# Thesis Project - modular Agent

## Description
Interoceptive origin of RL

**Project Motivation**: available Reinforcement learning (RL) models treat reward as a scalar signal emitted by
the environment; however, in biological agents, rewards are subjective, dynamic, and depend on the organism’s internal states and needs. 

This project will use insights from animal studies on primary reward circuits (Weber et al. 2025) to extend an **existing modular homeostatic RL** (Dulberg et al. 2023).
