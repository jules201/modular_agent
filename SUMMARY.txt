📝 WHAT EACH FILE DOES:

train.py
  ├─ Loads all parameters from config.py
  ├─ Creates World environment
  ├─ Creates Modular_DQN_Agent
  ├─ Trains for NUM_FRAMES steps
  ├─ Automatically saves agent every episode
  ├─ Prints progress every 100 steps
  └─ Shows training summary and statistics

test.py
  ├─ Finds or loads saved agent
  ├─ Recreates environment
  ├─ Runs agent for N episodes (no learning)
  ├─ Calculates metrics (reward, deviation, stability)
  ├─ Shows step-by-step behavior (optional)
  └─ Prints evaluation results

utils.py
  ├─ plot_training_curves() → 6-subplot figure
  ├─ plot_value_maps() → Module learned values
  ├─ plot_heatmap() → Where agent visited
  ├─ calculate_homeostasis_score() → Quality metric
  ├─ calculate_stability() → Variance metric
  ├─ analyze_agent_performance() → Detailed stats
  └─ save_agent_summary() → Text report
